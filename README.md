# 听答 Tingda · 开源 AI 面试练习与复盘

**把自己的回答录下来，让 AI 根据你实际说的内容找遗漏、给追问。**

Windows 本地运行，手机浏览器控制。结合目标岗位和简历练习，校正语音转写，生成面试复盘并导出 Markdown。完整本地功能采用 MIT 协议，无软件激活费用；模型和语音识别使用你自己的账户。

*An open-source mock interview practice tool for Windows: record your own answers, correct speech-to-text, and get AI feedback with follow-up questions.*

## 一次练习，留下具体的改进方向

1. **准备一道题**：填写目标岗位与简历背景，添加自己想练的面试问题。
2. **真的回答一次**：主动开启电脑麦克风，结束后校正转写；也可以直接输入实际回答。
3. **基于回答复盘**：查看说清楚的点、内容遗漏、表达建议与两个追问，导出 Markdown 后继续练。

## 下载后怎么用

1. [下载源码 ZIP](https://github.com/feju0384-star/interview-companion/archive/refs/heads/main.zip)，**先解压整个文件夹**，再双击 **安装并启动听答.cmd**。
2. 在电脑页面点击 **检测设备与连接**。手机与电脑连同一个 Wi-Fi，扫码进入控制台。
3. 在设置中连接自己的回答模型和语音识别服务，填写岗位与需要的背景。密钥在你自己的电脑上配置。
4. 打开 **练习复盘**，添加一道题 → 录我的回答 → 结束并校正 → 生成复盘 → 导出。

首次安装需联网，脚本会检查 Python 3.12（64 位）并安装项目依赖。下载耗时、设备与网络条件因电脑而异。**当前是源码安装方式，没有独立 EXE 安装器。**

还没配好语音识别时，可以先输入自己的回答；生成复盘仍需要可用的回答模型。手机连不上或设备检测失败，请看[安装与连接排查](docs/使用指南.md)。

## 提供哪些功能

| 功能 | 当前支持 |
| --- | --- |
| 面试练习 / mock interview | 添加问题，按岗位与简历背景练习 |
| 实际回答采集 | 电脑麦克风主动录音、分段转写、文字校正；支持直接输入 |
| AI 面试复盘 / answer review | 依据实际回答给具体建议、改进示例与后续追问 |
| 练习报告 | 导出带问题、实际回答与建议的 Markdown |
| 手机控制 | 浏览器扫码配对，不需要安装手机 App |
| 首次使用 | 安装脚本、设备检查、模型配置与连接诊断 |
| 模型选择 | 本机 Codex、Claude Code 或兼容 API；语音识别单独配置 |
| 其他练习辅助 | 系统声音转写、参考回答、允许场景下的屏幕题目解析 |

详细操作、模型接入、屏幕功能与限制见[完整使用指南](docs/使用指南.md)。

## 数据与使用边界

- **自备账户（BYOK）**：不提供共享密钥，调用费用付给你选择的模型与识别服务商。
- **麦克风由你开启**：音频分段发送给配置的识别服务；复盘时，问题、实际回答、岗位与简历发送给所选模型。云端数据保留以服务商政策为准。
- **导出后再退出**：当前练习记录在电脑进程内，清空或重启会丢失；需要留存请先导出。模型配置保存在电脑用户目录，源码不含个人配置。
- **用于练习**：AI 可能识别或评价错误，不保证面试结果。手机控制服务只用于可信局域网，具体安全与使用限制见使用指南。
