# 听答 Tingda · 开源 AI 面试辅助工具

**电脑听取问题，AI 生成参考回答，手机查看与控制。**

听答是一款 Windows AI 面试辅助工具：采集电脑系统声音并转写问题，结合岗位和简历生成参考回答，在手机浏览器中查看和控制；也支持屏幕题目识别与解析。实际回答录音、练习复盘与 Markdown 导出作为扩展功能提供。完整本地功能采用 MIT 协议，无软件激活费用；模型和语音识别使用你自己的账户。

*An open-source AI interview assistant for Windows: transcribe questions from system audio, generate reference answers with role and résumé context, and control the workflow from your phone. Also supports screen-question analysis and answer review.*

## 主要流程：听问题 → 参考回答 → 手机查看

1. **电脑采集问题**：选择面试软件使用的耳机或扬声器，开始监听系统声音，转写问题；也可以手动输入或校正问题。
2. **AI 辅助回答**：结合设置中的目标岗位和简历背景生成参考回答，文字逐步显示在手机上。
3. **手机查看与控制**：扫码连接后，在浏览器中查看回答、选择声音设备、调整设置、停止采集和管理会话。

## 下载后怎么用

1. [下载源码 ZIP](https://github.com/feju0384-star/interview-companion/archive/refs/heads/main.zip)，**先解压整个文件夹**，再双击 **安装并启动听答.cmd**。
2. 在电脑页面点击 **检测设备与连接**。手机与电脑连同一个 Wi-Fi，扫码进入控制台。
3. 在设置中连接自己的回答模型和语音识别服务，填写岗位与需要的背景。密钥在你自己的电脑上配置。
4. 在 **监听设置** 中选择实际使用的耳机或扬声器，点 **开始监听**，切到 **参考回答** 查看转写后的问题与 AI 回答。需要处理屏幕题时，停止监听后切到 **屏幕解题**，选择显示器和题目区域。

首次安装需联网，脚本会检查 Python 3.12（64 位）并安装项目依赖。下载耗时、设备与网络条件因电脑而异。**当前是源码安装方式，没有独立 EXE 安装器。**

还没配好语音识别时，可以先手动输入问题，使用已配置的回答模型；屏幕解析需要支持图片的模型。手机连不上或设备检测失败，请看[安装与连接排查](docs/使用指南.md)。

## 提供哪些功能

| 功能 | 当前支持 |
| --- | --- |
| 问题转写 | 采集选定耳机或扬声器的系统声音，分段识别面试问题；支持手动补充和校正 |
| AI 参考回答 | 结合岗位、简历与问题上下文，流式显示参考回答 |
| 手机查看与控制 | 浏览器扫码配对，查看答案、选择设备、修改设置和停止采集，无需安装手机 App |

| 首次使用 | 安装脚本、设备检查、模型配置与连接诊断 |
| 模型选择 | 本机 Codex、Claude Code 或兼容 API；语音识别单独配置 |
| 扩展：实际回答复盘 | 主动录制或输入自己的回答，校正文字后生成复盘、改进示例与追问，导出 Markdown |

详细操作、模型接入、屏幕功能与限制见[完整使用指南](docs/使用指南.md)。

## 数据与使用边界

- **自备账户（BYOK）**：不提供共享密钥，调用费用付给你选择的模型与识别服务商。
- **采集由你开启**：系统声音与麦克风音频分段发送给配置的识别服务；问题、岗位与简历发送给回答模型，屏幕解析发送所选区域的截图；生成复盘时另行发送实际回答。云端数据保留以服务商政策为准。
- **导出后再退出**：当前练习记录在电脑进程内，清空或重启会丢失；需要留存请先导出。模型配置保存在电脑用户目录，源码不含个人配置。
- **参考信息**：转写、识题、回答与复盘都可能出错，需自行核对。请用于允许辅助工具的面试、模拟面试等场景。手机控制服务只用于可信局域网，具体使用限制见使用指南。
