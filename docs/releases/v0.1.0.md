# 听答 v0.1.0 · 公开预览

首个 GitHub 预览版本，面向 Windows 上的模拟面试与实际回答复盘。完整本地功能采用 MIT 协议。

## 下载与开始

下载本页附件 **tingda-source.zip**，解压后进入 `tingda` 文件夹，双击 **安装并启动听答.cmd**。需要 Windows 10 / 11（64 位）、联网环境和自己的模型账户；首次安装会检查 Python 3.12 并安装依赖。这是源码安装包，不是独立 EXE。

电脑执行设备检查，手机同 Wi-Fi 扫码配对，配置回答模型和识别服务后，打开“练习复盘”。完整步骤见[使用指南](https://github.com/feju0384-star/interview-companion/blob/main/docs/%E4%BD%BF%E7%94%A8%E6%8C%87%E5%8D%97.md)。

## 已有能力

- 按题主动录制电脑麦克风、转写与校正实际回答，也可直接输入文字。
- 结合岗位与简历生成 AI 复盘、改进建议和两个追问，导出 Markdown。
- 手机浏览器扫码控制，设备与连接诊断、Python 安装与启动脚本。
- 本机 Codex、Claude Code 或兼容 API 回答，独立配置语音识别服务。
- 系统声音转写、参考回答，以及允许场景下的屏幕题目解析。

## 验证与已知限制

- 发布前 114 项自动化测试通过；模拟手机练习链路和真实模型复盘分别验证过。
- 截图使用虚构资料与模拟结果，不是实际用户评价。
- 未在所有设备、全新 Windows 安装环境和手机网络上完成验证；安装、音频与连通性问题欢迎提交 Issue。
- 模型及识别费用自理；AI 可能出错。练习记录在进程内，清空或重启前先导出。
- 不含共享密钥、账户配置、个人简历或真实录音。控制后台只供可信局域网使用。

这是 **Pre-release / 公开预览**，欢迎围绕安装、设备兼容和练习体验提供已脱敏的反馈。
