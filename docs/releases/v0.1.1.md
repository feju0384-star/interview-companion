# 听答 v0.1.1 · 项目介绍与联系入口更新

听答是一款 MIT 开源 AI 面试辅助工具：电脑转写问题，AI 生成参考回答，手机查看与控制，并支持屏幕题目解析和实际回答复盘。

本次更新简化了中英文介绍与帮助页面，统一保留直接联系邮箱；应用内也可以通过“有问题？联系我”找到联系方式。

## 下载与开始

下载附件 **tingda-source.zip**，解压后进入 `tingda` 文件夹，双击 **安装并启动听答.cmd**。需要 Windows 10 / 11（64 位）、联网环境及自己的模型与语音识别账户。当前为源码安装方式，首次安装会检查 Python 3.12 并安装依赖。

具体操作见[使用指南](https://github.com/feju0384-star/interview-companion/blob/main/docs/%E4%BD%BF%E7%94%A8%E6%8C%87%E5%8D%97.md)。
