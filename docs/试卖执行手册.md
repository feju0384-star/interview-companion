每周只判断三件事：

1. 哪个渠道带来真正适配且愿付费的用户？用有效咨询数作分母，不用浏览量冒充需求。
2. 收到的服务费扣掉退款和直接成本后，是否覆盖投入时间？个人时间也计入，不只看到账金额。
3. 重复出现的问题能否通过诊断和文档解决？优先修复最耗时的环节，再扩大接单量。

只有连续交付后发现用户频繁需要托管、调用量和支持成本也有真实记录，才设计含明确额度的订阅。机构版先访谈和小范围验证，独立约定部署、支持和数据处理范围。
